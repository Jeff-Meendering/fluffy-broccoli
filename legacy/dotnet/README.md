# Historical .NET / Java implementation

This is the pre-0.4 implementation, retained as migration reference for detector behavior, extraction fixtures and old tests. Cargo and active CI do not use it. The Rust implementation is under `crates/`; start with the repository-root README.

The archived layout was moved from the repository root. Old scripts, project-relative fixture paths and historical download manifests are not maintained as runnable setup instructions. Shared synthetic fixtures remain in the root `tests/fixtures`. Do not use the archived scripts to prepare Rust assets or publish current packages.

Historical assessments and notices are in `docs/history` at the repository root. Git history preserves the original runnable layout.
